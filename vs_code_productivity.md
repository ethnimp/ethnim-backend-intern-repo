# VS Code Keyboard Shortcuts

VS Code was already installed on my Mac. These are the 10 default macOS shortcuts I’d prioritise for backend development.

## Navigation

| Shortcut | What I’d use it for |
| --- | --- |
| `Cmd+P` | Find and open a file by typing part of its name. |
| `Cmd+Shift+F` | Search across the project for a route, error message or function name. |
| `Cmd+Shift+O` | Jump to a function, class or other symbol within the current file. |

## Editing

| Shortcut | What I’d use it for |
| --- | --- |
| `Cmd+D` | Select the next matching piece of text and add another cursor. Press it again to select more matches. |
| `Option+Cmd+Down` | Put another cursor on the line below so I can make the same edit on consecutive lines. |
| `Option+Shift+F` | Format the current file with its configured formatter. |

## Debugging

| Shortcut | What I’d use it for |
| --- | --- |
| `F9` | Set or remove a breakpoint on the current line. |
| `F5` | Start debugging the program or resume it after it pauses. |

## Terminal Commands

| Shortcut | What I’d use it for |
| --- | --- |
| `Control+Backtick` | Open or hide the integrated terminal for running a test or Git command. |
| `Control+Shift+Backtick` | Start another terminal so I can run commands while the first terminal runs a development server. |

## Which shortcuts do you think will be the most useful in your daily work?

I’d use `Cmd+P` and `Cmd+Shift+F` most often while getting familiar with the backend. If I’m trying to understand an API route, I can search for its path, then open the related service or test by name. `Cmd+D` would be useful when I need to edit a few matching pieces of text in the same file.

## How can keyboard shortcuts improve your productivity?

I can move from reading code to running a test without losing my place. For example, I can open a file, make a change, and use the integrated terminal to check it while keeping the code in view. Multiple cursors also let me make the same small edit in several places at once. I’d check the selections before typing so I change only the intended matches.
