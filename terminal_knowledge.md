# Terminal Setup and Command-Line Practice

## Which terminal client did you choose? Why?

I chose Apple Terminal with zsh because both are already available on my Mac. It’s a straightforward setup for navigating project folders, using Git and running development commands. I verified the app was installed and practised the commands below in a zsh session in my workspace.

## What customizations, if any, did you make?

I kept the standard setup for this exercise. My priority was getting comfortable with the basic commands before adding aliases, themes or plugins.

## What was the most useful command you learned today?

`pwd` was the most useful because it prints the full path of the folder I’m in. My Focus Bear workspace contains a separate clone of the internship repository. I ran `pwd` before and after using `cd` and saw the difference between the two folders. That gives me a quick check before I run a Git command or a project script.

I also used `ls -a` to see the files in the clone, including the hidden `.git` directory. Then I ran `git status --short --branch` to check that I was on `main` and see whether there were any local changes.
