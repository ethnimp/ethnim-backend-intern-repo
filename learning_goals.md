# Internship Learning Goals

## What do I hope to learn?

I want to learn how the backend of a real product works. At Focus Bear, I’d like to follow a request from the app into a NestJS controller, through the service that handles it, and into PostgreSQL. I also want to see how the team takes a change from a GitHub issue through implementation, testing and code review.

## What skills am I most excited to develop?

I’m most excited to build a REST API in TypeScript with NestJS. I’d like to create a small endpoint, validate what the user sends, and check what happens with both valid and invalid requests. I also want to use Bruno and VS Code breakpoints to see where a request goes wrong, then use Jest and Supertest to make sure the fix holds up.

## What can I contribute to the team?

Exploring Focus Bear as a new user helped me spot where the app could be clearer. I can bring that perspective to backend work by writing clear steps to reproduce issues, checking edge cases and explaining the expected behaviour. I’d like to start with a small fix, test or documentation update, and raise blockers early so the team knows where I need help.

## What area would I like to improve?

I haven’t used Node.js yet, so that’s where I feel least confident. I want to start by running a small JavaScript script with Node.js, learning how npm scripts and dependencies work, and getting comfortable with `async` and `await`. Then I can use those basics to run a NestJS project and understand what happens when it receives a request.

## What would a successful internship look like?

I’d like to finish the internship able to run the backend locally, follow a request from the API to the database, and work out where to look when something fails. A concrete milestone would be getting one small backend change through team review with a test that shows what changed. I’d want to be able to explain how I checked it and what I learned from the review.
